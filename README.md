-Data Analysis Agent
An intelligent, interactive CLI-based Data Analysis Agent that allows you to query datasets using natural language, execute SQL operations, perform statistical tests, and persist business logic definitions across sessions.

-Features
Natural Language Queries: Ask plain-English questions about your tabular data (e.g., CSV files).

Automated Tool Tracing: See underlying tool executions such as SQL generation (run_sql) and statistical evaluation (statistical_test).

Session Memory & Custom Definitions: Define business terms on the fly (e.g., saving @active_customers) so they persist across sessions.

Multi-Dataset Support: Switch effortlessly between different data domains like customer metrics or employee records.
